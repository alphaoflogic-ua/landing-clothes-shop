# Лендинг з компонентів

Один репозиторій — один лендинг. Лендинг збирається з компонентів. Кожен
компонент робиться окремо, перевіряється на своїй сторінці, а потім ставиться
на лендинг.

Інструменти: VS Code + Live Server, Chrome, Git. Без збірника.

## Налаштування (один раз)

1. Встанови VS Code, Git, Chrome.
2. Відкрий папку репозиторію у VS Code і погодься встановити рекомендовані
   розширення: **Live Server**, **Prettier**, **EditorConfig**.
3.**видалено**
4. Натисни **Go Live** справа внизу у VS Code. Відкриється
   `http://127.0.0.1:5500/` — лендинг. Вітрина компонентів —
   `http://127.0.0.1:5500/showcase.html`.

Live Server запускай з кореня репозиторію (папка, де лежить цей файл).

## Структура

```
index.html                 лендинг
showcase.html              вітрина: список компонентів, показує будь-який окремо
css/tokens.css             кольори, відступи, шрифти — змінні для всіх компонентів
js/components.js           список компонентів — сюди дописуєш новий
js/include.js              ставить компоненти на сторінку (не редагується)
images/
  example/                 картинки компонента, тека з його іменем
components/
  example/                 еталонний компонент — копіюй його, коли робиш новий
    example.html           сторінка компонента
    example.css            стилі компонента
    example.js             поведінка компонента
```

## Компонент

Компонент — це тека `components/<name>/` з трьома файлами:

- `<name>.html` — звичайна сторінка. Підключає `tokens.css` і свій CSS,
  у `<body>` лежить компонент — елемент з класом `<name>`. Відкриваєш її в
  Live Server: `http://127.0.0.1:5500/components/card/card.html`.
- `<name>.css` — стилі.
- `<name>.js` — поведінка. Експортує `init(container)`.

Після створення теки додай імʼя у `js/components.js`:

```js
export const components = ['example', 'card'];
```

Без цього ні лендинг, ні вітрина компонент не побачать.

Внизу `<name>.html` два рядки запускають поведінку на цій сторінці:

```html
<script type="module">
  import { init } from './card.js';
  init(document);
</script>
```

### Правила

1. **Класи з префіксом.** Усі класи починаються з імені компонента:
   `card`, `card__title`, `card__price`. Варіант або стан — `card--wide`.
2. **Без зовнішніх відступів.** Компонент не задає собі `margin`, `position`,
   ширину сторінки. Де він стоїть — вирішує сторінка.
3. **Кольори, відступи, шрифти — тільки змінні з `tokens.css`.**
4. **Картинки — в `images/<name>/`,** шлях від кореня, зі слешем:
   `<img src="/images/card/laptop.jpg" alt="Ноутбук Asus Zenbook" />`.
   Так само всі інші шляхи: `/css/tokens.css`, `/components/card/card.css`.
   Тоді вони працюють і на сторінці компонента, і на вітрині, і на лендингу.
5. **Кнопка — це `<button>`, у картинки є `alt`.**
6. **`init` шукає всі копії компонента** через `querySelectorAll` і цикл, бо
   на лендингу карток буде багато.
7. **У консолі немає помилок.**

## Вітрина

`showcase.html` читає `js/components.js`, показує список зліва; клік по імені —
і компонент зʼявляється на білому аркуші з пунктирною рамкою, щоб було видно
його межі. Посилання виду `showcase.html#card` відкриває одразу потрібний компонент —
його і вказуй у pull request.

## Лендинг

`index.html` не містить розмітки компонентів. На місці кожного блоку стоїть:

```html
<div data-include="card"></div>
```

`js/include.js` при завантаженні сторінки бере з `components/card/card.html`
елемент `.card`, підключає `card.css`, імпортує `card.js` і викликає `init`.
Цей `div` лишається обгорткою — на ньому лендинг задає відступи й місце
в сітці.

Якщо імені немає в `js/components.js`, у теці не вистачає файла або в
`card.html` немає елемента з класом `card` — на місці блоку буде текст
`Failed to include "card"`, а в консолі — помилка з причиною.

## Робочий процес

1. `git switch main` → `git pull`.
2. Гілка під компонент: `git switch -c feat/card`.
3. Скопіюй `components/example/` у `components/card/`, перейменуй файли
   і класи. Додай `'card'` у `js/components.js`.
4. Зроби компонент: розмітка → стилі → поведінка. Перевіряй на
   `showcase.html#card` або прямо на `components/card/card.html`.
5. Постав `<div data-include="card">` на лендинг.
6. Коміти невеликі, повідомлення англійською, з дієслова:
   `Add card markup`, `Style card`, `Add card button handler`.
7. `git push -u origin feat/card` → Pull Request. У описі — посилання
   `showcase.html#card`, чеклист відмічений.
8. Виправлення після ревʼю — у ту саму гілку. Потім merge.

Одна гілка = один компонент = один pull request.
